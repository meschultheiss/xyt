# Licence et citation

## Décision de travail

Le package adopte une structure de licence en trois niveaux :

| Élément | Licence ou conditions | Intention |
|---|---|---|
| Code source Python | PolyForm Noncommercial License 1.0.0 | Permettre l’usage, la modification et le partage dans des cadres non commerciaux. |
| Documentation, tutoriels et figures | Creative Commons Attribution-NonCommercial 4.0 International | Permettre la réutilisation avec attribution, hors usages commerciaux. |
| Données de démonstration | [À DÉFINIR] | À préciser lorsque le jeu de démonstration stable sera publié. |

Cette décision correspond à l’objectif suivant : permettre une réutilisation libre dans les cadres de recherche, d’enseignement, d’évaluation et de développement non commercial, tout en évitant qu’un tiers transforme directement le travail en produit ou service commercial sans accord.

## Ce que cela permet

Les usages suivants sont autorisés, sous réserve de respecter les licences et de citer la source :

- installer et tester le package ;
- lire, modifier et adapter le code pour un usage non commercial ;
- utiliser le package dans un projet de recherche, d’enseignement, d’évaluation ou de démonstration ;
- réutiliser la documentation avec attribution, dans un cadre non commercial ;

## Ce qui nécessite un accord écrit

Les usages suivants nécessitent un accord écrit préalable de Bureau Action Située :

- intégrer `xyt_gps` dans un produit ou service commercial ;
- vendre une prestation, un logiciel ou une plateforme reposant directement sur le package ;

## Fichiers de référence

Les fichiers de licence se trouvent à la racine du dépôt `xyt-gps` :

- `LICENSE` : texte de la PolyForm Noncommercial License 1.0.0 pour le code source ;
- `LICENSE.docs` : texte de la licence CC BY-NC 4.0 pour la documentation ;
- `NOTICE.md` : attribution, financeurs et citation recommandée.

## Point de vigilance

PolyForm Noncommercial et CC BY-NC ne sont pas des licences open source au sens strict, car elles limitent les usages commerciaux. Ce choix est cohérent avec l’objectif de réutilisation non commerciale, mais il est moins permissif qu’une licence comme Apache-2.0.

Avant publication sur PyPI ou diffusion publique large, il reste prudent de faire relire cette structure de licence par une personne compétente en propriété intellectuelle.
