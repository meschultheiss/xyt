# Licence spécifique du jeu de données sample xyt_gps

Date : 2026-06-09

## Objet

Cette licence concerne uniquement le jeu de données sample utilisé pour la démonstration du package `xyt_gps`, notamment le fichier :

```text
xyt-main-archive/tests/sample_data/sample_data_marced_motiontag.pkl
```

Ce fichier contient des données GPS personnelles de Marc-Edouard, mises à disposition exclusivement pour apprendre, tester et documenter le package.

## Usages autorisés

Le jeu de données sample peut être utilisé pour :

- exécuter les tutoriels et exemples du package `xyt_gps` ;
- tester localement le chargement, la validation et la transformation des données ;
- illustrer le format attendu des données brutes ;
- enseigner ou démontrer le fonctionnement du package dans un cadre non commercial.
