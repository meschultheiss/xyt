# Exemples historiques

Ce dossier conserve les anciens notebooks et scripts de démonstration utilisés
pendant la stabilisation du package.

Ils ne constituent plus le parcours recommandé. Plusieurs références internes
peuvent pointer vers l'ancien dossier local `Data/Output/test-set-gps` ou vers
des générateurs de données de travail. Pour apprendre ou reprendre le package,
utiliser les notebooks situés directement dans `package-xyt-gps/examples/` :

- `quickstart-analyse-gps.ipynb` ;
- `diagnostiquer-ses-donnees.ipynb` ;
- `demo-fil-rouge-pipeline.ipynb` ;
- `demo-qualite-visualisations-test-set.ipynb`.

Les fichiers de ce dossier servent uniquement de mémoire technique.
